Pipeline bugs are tracked in the Linear project "INGEST", not in the general engineering backlog.

**Why:** the team split bug tracking by subsystem after the shared backlog got too noisy to triage; pipeline-specific issues get their own view and on-call rotation there.

**How to apply:** when the user references a pipeline bug or asks to check ticket status, look in the INGEST project first rather than searching the general backlog.
